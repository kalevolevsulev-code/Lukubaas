# V1.1 serveri seadistus

V1.1 serverikiht kasutab:
- Netlify Functions
- Supabase PostgreSQL
- ühte tabelit `projects`

## 1. Supabase

Loo Supabase projekt.

Ava SQL Editor ja käivita fail:
`supabase/schema.sql`

See loob:
- `projects` tabeli
- unikaalsuse `project_code + project_version`
- immutable kaitse UPDATE/DELETE vastu
- vajalikud indeksid

## 2. Netlify environment variables

Netlify projektis lisa kaks environment variable'it:

`SUPABASE_URL`
- Supabase Project URL

`SUPABASE_SERVICE_ROLE_KEY`
- Supabase server-only service role key
- seda EI TOHI lisada brauseri JavaScripti ega GitHubi

## 3. Deploy

Deploy branch:
`feature/v1.1-server`

Netlify kasutab repo failist `netlify.toml`:
- publish directory: `.`
- functions directory: `netlify/functions`

## 4. Test

1. Ava V1.1 server branch deploy.
2. Loe Excel.
3. Genereeri süsteem.
4. Kinnita projekt.
5. Koosta snapshot.
6. Vajuta "Salvesta serverisse".

Õnnestumisel kuvatakse:
- projekti serveri ID
- projectCode
- projectVersion

Server kontrollib:
- projekt on CONFIRMED
- snapshot schemaVersion = 1.1
- engineVersion = 1.0.4
- checksum vastab snapshoti tegelikule sisule
- sama projectCode + projectVersion ei eksisteeri juba

Serveri või võrgu vea korral jääb lokaalne generaator edasi tööle.
