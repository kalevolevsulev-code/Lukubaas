# V1.1 serverikihi töökindluse reeglid

1. V1.0.4 Stable generaatori tuum jääb muutmata.
2. Serverikood paikneb eraldi moodulis.
3. Serveri rike ei blokeeri generaatori lokaalset tööd.
4. Serverisse salvestatakse ainult kinnitatud projekt.
5. Kinnitatud snapshot on immutable.
6. Sama `projectCode + projectVersion` kombinatsioon peab olema unikaalne.
7. Kõik serverivastused valideeritakse.
8. Timeout- ja võrguvead käsitletakse kasutajale arusaadavalt.
9. Salvestamise järel kontrollitakse serverist tagastatud ID-d, projektikoodi, versiooni ja checksum'i.
10. Iga serverikihi muudatus peab läbima V1.0.4 regressioonikontrolli.
11. Server ei tohi muuta generaatori arvutustulemust.
12. Turva- ja kvaliteedireeglid on serverifunktsioonidest kõrgema prioriteediga.
